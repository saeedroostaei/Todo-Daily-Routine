# 📝 TODO DONE - برنامه کارهای روزمره

یک اپلیکیشن مدرن، سریع و کاربرپسند برای مدیریت کارهای روزانه که با استفاده از HTML، CSS و JavaScript خالص (Vanilla) طراحی و توسعه داده شده است. این پروژه دارای رابط کاربری زیبا با افکت‌های شیشه‌ای (Glassmorphism) و قابلیت‌های متنوعی برای افزایش بهره‌وری است.

## ✨ امکانات (Features)

- **افزودن، ویرایش و حذف تسک‌ها:** مدیریت کامل کارهای روزانه.
- **تنظیم زمان و هشدار (Reminder):** با رسیدن به ساعت مشخص شده برای هر تسک، سیستم هشدار (نوتیفیکیشن) نمایش می‌دهد.
- **اولویت‌بندی:** تعیین سطح اهمیت برای هر کار (بالا، متوسط، پایین، معمولی) با نمایش رنگی.
- **فیلتر کردن:** مشاهده تسک‌ها بر اساس وضعیت (همه، در حال انجام، انجام شده).
- **شمارنده پیشرفت:** دایره هوشمند که با تغییر وضعیت تسک‌ها، رنگ و عدد آن (تعداد انجام‌شده به کل) تغییر می‌کند.
- **حالت تاریک و روشن (Dark/Light Mode):** قابلیت تغییر تم برنامه.
- **ذخیره‌سازی خودکار:** تمام اطلاعات با استفاده از `LocalStorage` در مرورگر ذخیره می‌شوند و با رفرش صفحه پاک نمی‌شوند.
- **طراحی واکنش‌گرا (Responsive):** سازگار با موبایل و دسکتاپ.

## 🛠 تکنولوژی‌های استفاده شده (Built With)

- HTML5
- CSS3 (Flexbox, CSS Variables, Animations)
- JavaScript (ES6+, DOM Manipulation, LocalStorage)
- Google Fonts (Vazirmatn)

## 🚀 نحوه اجرا (How to Run)

برای اجرای این پروژه در سیستم خود، کافی است مراحل زیر را طی کنید:
1. ریپازیتوری را کلون کنید یا فایل‌ها را دانلود کنید.
2. فایل `index.html` را در مرورگر خود باز کنید. (پیشنهاد می‌شود از افزونه Live Server در VS Code استفاده کنید).
